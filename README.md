🚀 Just launched the first version of a real-time Developer MeetUp platform!
This web application is built with a strong focus on beautiful and essential developer-centric functionality — aiming to empower developers to connect, collaborate, and grow their network.

🔧 Key Features Include:

🔐 User authentication with customizable developer profiles

📍 Real-time meetup creation, discovery, and registration

🔍 Advanced search/filter by location, tech, and date

🔔 Real-time notifications for updates and new events

🌗 Dark/light mode toggle with responsive design

🗓 Calendar integration for easy event tracking

🎥 “Host a Meetup” feature 

📖 Engaging About Us, Careers, and Support Center pages

🎨 Design Highlights:

Modern color palette (Purple #8B5CF6, Teal #0D9488, Orange #F59E0B)

Frosted glass effects, subtle animations, and clean typography

Card-based UI, custom iconography, and grid background patterns

🧠 Mission: To build a community-driven space where developers can discover opportunities, share knowledge, and collaborate in real-time.
